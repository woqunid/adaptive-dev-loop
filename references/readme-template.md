## 文件清单与作用

| 文件 | 类别 | 作用 |
|------|------|------|
| `loop.md` | 默认主文件 | 本需求从需求到交付的主记录 |
| `README.md` | 索引 | 本目录导航、各文件作用、当前进度（即本文件） |
| `analysis.md` | 分析与方案 | 当前项目现状(含原有规范) + 修改方案 + 关键决策(ADR) |
| `tasks.md` | 执行 | 任务拆分与进度 |
| `iteration-log.md` | 循环追踪 | 自适应循环每轮的问题/根因/修复/结果 |
| `final-report.md` | 交付 | 最终交付报告 |

> 进入任一阶段前先读取 `loop.md` 与相关拆分产物，确保基于最新事实而非记忆推进。
